# Asset-dimension sensitivity

## Experiment design

- Design: growing-block equicorrelated Gaussian.
- Asset grid: `n = {5,10,15,20,25,30,35,40,45,50}`.
- Horizon: `T = 50`.
- Training sample size: `Ntr = 300`.
- Evaluation sample size: `Nev = 1000`.
- Monte Carlo replications: `S = 2000`.
- Initial wealth: `x0 = 1`.
- Regularization parameter: `lambda = 1e-4`.
- Factor count: `K_n = n/5`.
